# Code of Conduct

This project adopts the **Contributor Covenant**, version 2.1, as its
Code of Conduct. The full text — which defines expected behavior,
unacceptable behavior, enforcement responsibilities, and the
enforcement guidelines — is maintained upstream and applies to this
project verbatim:

- Plain text: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
- Markdown:   <https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.md>

## Scope

This Code of Conduct applies within all project spaces — the GitHub
repository, issues, pull requests, discussions, and any other
communication channel associated with the project — and also when an
individual is officially representing the project in public spaces.

## Reporting

To report a concern privately, please open a confidential security
advisory on the repository
([Security tab → Report a vulnerability](https://github.com/ritbikbharti/AkamaiEdgeDiagnosticsMCP/security/advisories/new))
— GitHub's advisory system supports private maintainer-only
communication and is the most reliable channel.

All reports are reviewed and investigated promptly and fairly. The
maintainer is obligated to respect the privacy and security of the
reporter of any incident.

## Enforcement

Maintainers will follow the
[Community Impact Guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines)
from Contributor Covenant 2.1 when determining the consequences of any
action they deem in violation of this Code of Conduct.
